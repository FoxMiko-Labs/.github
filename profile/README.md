# RandomProject Labs

Android kernel development organization focused on stable and optimized kernel builds for Qualcomm Snapdragon-based Xiaomi devices.
This is Personal Project, basically to experience learning.

---

## Active Projects

| Repository | Device | Codename | SoC | Status |
|---|---|---|---|---|
| [kernel_xiaomi_surya](https://github.com/RandomProject-Labs/kernel_xiaomi_surya) | POCO X3 NFC | `surya` | Snapdragon 732G | Active |
| [kernel_android_sm6250](https://github.com/RandomProject-Labs/kernel_android_sm6250) | Redmi Note 9 Pro / Miatoll | `joyeuse` | Snapdragon 720G | Active |

---

## Focus

- Stability and efficiency with balanced performance
- Compatibility across AOSP, MIUI, HyperOS, and ported ROMs
- Upstreaming patches from Linux stable and CodeLinaro
- Upstreaming based on LineageOS
